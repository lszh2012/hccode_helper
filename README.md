## ✨ 核心功能

- 🤖 **AI 随行讲解**：支持 豆包、DeepSeek、Kimi 三款大模型。
  - 点击悬浮按钮一键复制纯文本题目（自动过滤导航栏和 IDE 干扰）。
  - 自动拼装 `语言C++` 提示词并跳转对应 AI 网站。
  - **Kimi** 支持自动填入并发送；**DeepSeek** 支持自动填入；**豆包** 自动复制并提示手动粘贴。
- 🚫 **比赛防作弊**：当检测到 URL 包含 `/contest/`（比赛页面）时，强制隐藏 AI 辅助按钮，守护比赛公平。
- 🎨 **界面自定义**：
  - 支持输入直链更换网页背景图（带一键清空恢复默认功能）。
  - 🪟 **毛玻璃 UI (Beta)**：适配了主流的 Element UI 和 vxe-table 组件，一键开启全局半透明模糊质感。
- 🧩 **主页净化**：
  - 内置主页常见卡片（欢迎卡片、公告、近期比赛等）的开关。
  - 支持通过“点选隐藏”精准屏蔽不喜欢的页面模块。
  - 支持隐藏规则的导入、导出与恢复出厂设置。
- 💾 **全量备份**：一键将背景图、毛玻璃开关、隐藏卡片、AI按钮坐标打包导出为 JSON 文本，换电脑一键恢复。

## 📥 安装与下载

### 方式一：直接下载打包版（推荐）
前往 [官网下载](https://hccode-helper.rth1.xyz/) 或蓝奏云盘下载最新版 ZIP 压缩包。
> 蓝奏云链接：[点击前往](https://wwblz.lanzouu.com/b01euq0gti) (提取码: `hczs`)

### 方式二：源码加载（开发者模式）
1. 将本仓库克隆或下载到本地并解压。
2. 打开 Chrome 或 Edge 浏览器，地址栏输入 `chrome://extensions/`。
3. 开启右上角的 **“开发者模式”**。
4. 点击 **“加载已解压的扩展程序”**，选择包含 `manifest.json` 的文件夹即可。

## 📖 使用指南

- **AI 按钮**：在普通题目页或训练题目页右下角（或你拖拽后的位置）会出现一个 🤖 悬浮球。点击即可选择 AI，按住可拖拽调整位置。
- **设置面板**：点击浏览器右上角的扩展图标，即可呼出控制台，进行背景、毛玻璃和隐藏卡片的配置。

*注：部分功能（如网页背景图）需要刷新页面后生效。*
